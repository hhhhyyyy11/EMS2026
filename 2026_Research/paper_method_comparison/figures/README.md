# 論文用図

再現可能な実験結果から生成した図と、その生成元を記録する。

- `T11_E2_accuracy_time.png`: E2のSOC格子、期間、時間刻みとMILP基準費用差・計算時間。
- `T11_E3_season.png`: E3の季節週別のMILP基準費用差・計算時間。
- `T11_E4_battery.png`: E4の出力/容量比とMILP基準費用差・計算時間。
- 生成元の数値、設定、再現処理は `tables/T11_*.csv`、`tables/E5_selection.csv`、`config/e2_*.json`、`config/e3_*.json`、`config/e4_*.json`、`src/summarize_t11.py`。
