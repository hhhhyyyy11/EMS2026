# 小規模検証ケース

作業ID：T04（人工ケース）、T05・T06（求解回帰検査）

求解器を使わずに手計算できる問題、正しい時系列、期待する料金内訳をJSONで保存する。人工ケースの設備条件と基本料金係数は検査専用であり、`config/common_problem.json` の実データ条件とは別である。

| ケース | 内容 | 手計算結果 |
|---|---|---|
| A | PVなし、効率1、一定需要・一定価格、待機 | 最大買電2 kW、電力量30円、基本料金8円、合計38円 |
| B | 2時刻の価格差、安価時に1 kWh充電して高価時に放電 | 買電2/0 kW、電力量20円、基本料金10円、合計30円。待機は45円 |
| C | 一定価格、余剰PV、充放電効率0.8 | PV入力1.5625 kWh、負荷供給1 kWh、往復損失0.5625 kWh、合計料金0円。全量抑制する待機は12円 |
| D | BのSOC、電力、終端値、最大買電、料金内訳、排他を個別に破壊 | 各変異について指定した違反名を検出 |

許容差の既定値は、電力 `1e-6 kW`、SOC収支・境界 `1e-6 kWh`、費用 `max(0.01円, 再計算値の絶対値×1e-8)` である。評価結果の `tolerances` と `cost_tolerance_yen` に実際の値を残す。

全ケースを実行する：

```bash
../.venv/bin/python -m unittest discover -s tests/small_cases -p 'test_*.py' -v
```

T06のDPではA・Bを3点格子、Cを9点格子で解く。Cの9点格子は、手計算解の中間SOC 1.25 kWhを厳密に含む。Bでは、終端SOCにおいて「最大買電1 kW・電力量40円」と「最大買電2 kW・電力量20円」の2ラベルが非劣として残り、基本料金を加えた後者30円が選ばれることも検査する。

単一の正解ケースを検査する：

```bash
../.venv/bin/python src/evaluate_solution.py tests/small_cases/case_b_arbitrage.json
```

終了コードは合格0、制約または報告値の不一致1、入力形式エラー2である。`evaluate_solution()` はソルバーへ依存せず、T05以降から正規化した問題・時系列・報告値を直接渡して利用できる。
