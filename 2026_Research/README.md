# 2026年度 EMS共同研究

このフォルダを2026年度の研究作業の起点とする。

## 研究テーマ

1. デマンド目標値・契約電力履歴を考慮したEMSのLP計画
2. 同一EMS問題に対するLPとDPの性能・解品質・計算量比較

## フォルダ

- `src/`: 今年度の実行コード
- `Shared/`: 今年度コードが参照する共通処理（互換性のため名称を維持）
- `Data/`: 入力データ
- `results/`: 再現可能な実験結果
- `reports/`: 週次・月次報告
- `MeetingHistory/`: トランスクリプト・議事録
- `references/`: 研究テーマ資料・過年度成果への参照
- `planning/`: 研究計画、整理記録、報告構成案

## 実行上の注意

- 原則としてこのフォルダをカレントディレクトリにして実行する。
- 整理時点で未ダウンロードだった主要ソース、設定、入力データは、移動後にローカル化された。過年度の一部PDF・TeXのみ未ダウンロード状態が残るが、今年度コードの実行には影響しない。
- 生データと実験条件を変更した場合は、`results/` に条件名を付けたサブフォルダを作り、既存結果を上書きしない。
- 最適化の実行には `requirements.txt` の依存関係が必要。整理時に重複仮想環境を削除したため、新しい環境を1つだけ作成して依存関係を導入する。

## 7月報告の中心命題

SOC更新式を統一して再計算すると、従来法と履歴考慮法の年間費用差は0円となった。旧499円差はモデル不一致によるものだった。充放電排他用の二値変数を含むため、今回の実験モデルは厳密にはMILPである。7月は、過去ピークの大きさ、失効時期、外部から与えるデマンド目標値を変えた96条件により、実行可能性と費用の変化を示す。
